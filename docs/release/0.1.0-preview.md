# OpenDevice Forge 0.1.0 preview

OpenDevice Forge is a desktop and Android module host. Phone-local LLM inference and remote API access are optional modules rather than the product shell.

## Included

- macOS and Windows desktop workbench for read-only Android discovery, inspection and bounded plugin workflows.
- Android arm64 host that opens on Modules and can show device facts without an AI model.
- Optional local AI node using a pinned `llama.cpp` runtime, retained local model, local chat and an authenticated OpenAI-compatible endpoint.
- App-level workload and thermal limits without Root or system protection changes.
- Package-v1 P-256 verification, explicit trust, permission review, private version storage and rollback protection on both hosts.

## Preview limitations

- Desktop artifacts are not Developer ID / Authenticode signed or notarized.
- The Android artifact uses standard debug signing, targets arm64-v8a and is not a Play Store release.
- The online module catalog, download review UI and live activation of downloaded packages are not included.
- No public compatibility promise is made for a specific phone. The current evidence includes one Huawei CDL-AN50 on Android API 29, recorded separately in the verification docs.

## Verify downloads

Compare each downloaded file with the matching `checksums-*.txt` attached to the draft Release. Do not install an artifact whose checksum differs.
